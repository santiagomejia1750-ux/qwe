# Proyecto: Distribuciones estadísticas unidimensionales y bidimensionales

Sitio web académico elaborado con Quarto y HTML, CSS y JavaScript. Incluye explicaciones, tablas, representaciones gráficas y recursos para el estudio de las distribuciones de frecuencias.

## Ver el proyecto

Una vez publicado con GitHub Pages, el sitio estará disponible en:

`https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/`

Reemplaza `TU-USUARIO` y `NOMBRE-DEL-REPOSITORIO` por los datos de tu cuenta y repositorio.

## Publicar en GitHub Pages

1. Crea un repositorio **público** en https://github.com/new.
2. Extrae este ZIP y sube **el contenido de esta carpeta** al nivel principal del repositorio. `index.html` debe quedar en la raíz, no dentro de otra carpeta.
3. En GitHub, abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/(root)`, y pulsa **Save**.
6. Espera unos minutos y actualiza la sección **Settings → Pages** para ver el enlace publicado.

## Archivos principales

- `index.html`: página web lista para publicar.
- `styles.css`: estilos visuales.
- `index_files/`: recursos JavaScript, CSS e imágenes usados por la página.
- `index.qmd`: archivo fuente de Quarto para futuras modificaciones.
- `Logo_ut.png`: imagen del proyecto.

## Desarrollo

El HTML existente se puede publicar directamente; no es necesario instalar Quarto para desplegar la versión ya generada. Si editas `index.qmd`, necesitarás Quarto para volver a generar `index.html`.
